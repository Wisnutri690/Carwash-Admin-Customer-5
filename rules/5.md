# 1. PROJECT OVERVIEW

Project 5 is a fullstack Carwash Management Application.

The project consists of:

- Backend
- Frontend

The existing backend from previous projects should be reused and developed further.

Do not rebuild the backend from zero unless explicitly discussed.

The backend should be extended to support both:

- Admin
- Customer

---

# 2. USER ROLES

The application has two main roles:

ADMIN
CUSTOMER

Each role has:

- different authentication
- different dashboard
- different permissions
- different application flow

---

# 3. ADMIN AUTHENTICATION

Admin authentication uses:

- Email
- Password
- JWT

General flow:

Admin
↓
Login
↓
Backend validates credentials
↓
JWT generated
↓
Admin authenticated
↓
Admin Dashboard

The existing JWT authentication implementation should be reused where possible.

Do not replace the existing authentication architecture without discussion.

---

# 4. CUSTOMER AUTHENTICATION

Customer authentication uses:

EMAIL.

Customer does not use a traditional password.

The customer's email must be unique in the database.

General flow:

Customer
↓
Enter Email
↓
Backend checks customer
↓
Customer exists?

JIKA CUSTOMER ADA

Customer exists
↓
Continue customer authentication flow
↓
Customer Dashboard

JIKA CUSTOMER BELUM ADA

Customer does not exist
↓
Redirect to Customer Registration
↓
Customer enters required information
↓
Customer account/data created
↓
Continue authentication flow
↓
Customer Dashboard
